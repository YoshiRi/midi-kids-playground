🎹 MIDIキーボードの つなぎかた（PC / Android / iPad）

💻 PC（Mac / Windows / Chromebook）

  1. MIDIキーボードをUSBケーブル（またはBluetooth MIDI）でPCに繋ぎます。
  2. Google Chrome / Microsoft Edge / Firefox でこのページを開くと自動で認識します。
  3. キーボードがないときも、PCのキーボード（A S D F G H J K）や画面クリックで遊べます！

🤖 Android（タブレット / スマホ）

  1. MIDIキーボードを USB-Cケーブル（または OTG アダプタ）で Android 端末に繋ぎます。
  2. 標準の Google Chrome でこのページを開きます（専用アプリ不要です）。
  3. 初回に「MIDI デバイスの制御を許可しますか？」と表示されたら「許可」をタップすると自動で認識します。

💡 電力消費が大きいキーボードで電源が入らない場合は、キーボード側を電池駆動にするか給電付き USB-C ハブ経由で繋いでください。Bluetooth MIDI は「MIDI+BTLE」等のアプリで一度ペアリングすると Chrome から認識されます。

📱 iPad で MIDIキーボードを繋ぐ方法

⚠️ iPad標準の Safari / Chrome は WebKit の制約により Web MIDI API に未対応です。以下の手順でMIDIキーボードがそのまま動きます！

  1. iPadとMIDIキーボードを USB-Cケーブル（Lightning機種はカメラアダプタ）または Bluetooth MIDI で接続します。
  2. App Store から Web MIDI 対応ブラウザ（例: Web MIDI Browser）をインストールします。
  3. そのアプリの中でこのページのURLを開くと、MIDIキーボードを自動で認識します！
  4. ケーブルがないときでも、標準Safariで画面の大きな鍵盤をマルチタッチして遊べます。

💡 音が鳴らないときのチェック

  • 画面に出ている「🔊 ここをタップして おとをだす！」ボタン（または鍵盤）を1回タップすると音声が有効になります。
  • 設定（⚙️）の「🎵 テストおん」で音が鳴るか確認できます。
  • 「やさしい」「まつモード」はどのオクターブを弾いても反応するので、25鍵ミニキーボードでも安心です。
