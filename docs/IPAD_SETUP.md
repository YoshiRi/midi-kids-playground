# PC / Android / iPad と MIDIキーボードの接続ガイド

## 対応状況まとめ

| 端末 | ブラウザ | Web MIDI API | 備考 |
|---|---|---|---|
| **PC (Mac / Win / Chromebook)** | Chrome / Edge / Firefox | ✅ 標準対応 | ケーブルを挿すだけで即OK |
| **Android タブレット / スマホ** | Chrome（標準） | ✅ 標準対応 | 専用アプリ不要でそのまま動く |
| **iPad / iPhone** | Safari / Chrome / Firefox | ❌ 非対応 | iPad版Chromeも中身がWebKitのため非対応 |
| **iPad / iPhone** | **Web MIDI Browser** 等 | ✅ アプリ経由で対応 | アプリ内ブラウザでURLを開くと動く |

---

## 💻 PC（Mac / Windows / Chromebook）で遊ぶ

1. MIDIキーボードを USB ケーブル（または Bluetooth MIDI）で PC に接続します。
2. 以下の Web MIDI API 対応ブラウザでこのサイトを開きます。
   - **Google Chrome**（おすすめ）
   - **Microsoft Edge**
   - **Firefox**（初回に MIDI アクセスの許可ダイアログが出ます）
3. 右上のステータスが `🎹 MIDI接続中: <キーボード名>` に変わったらそのまま遊べます。

> MIDIキーボードがなくても、PCキーボード（`A W S E D F T G Y H U J K`）やマウスクリックで全ゲームをテスト・プレイできます。

---

## 🤖 Android タブレット / スマホで遊ぶ（おすすめ・専用アプリ不要）

Android の標準 **Google Chrome** は Web MIDI API に対応しているため、iPad のような専用ブラウザは不要です。

1. **ハードウェア接続**
   - **USB 接続**: USB-C ケーブル（または OTG アダプタ）で MIDI キーボードを Android 端末に繋ぎます。
     - バスパワー（USB給電）のキーボードで電力が足りない場合は、キーボードを電池/AC駆動にするか、給電対応の USB-C ハブ経由で接続してください。
   - **Bluetooth MIDI**: 通常の Bluetooth 設定では MIDI 機器として見えないことがあるため、「MIDI+BTLE」などの無料ユーティリティで一度接続すると Chrome から認識されます。
2. **Chrome で開く**
   - Chrome でこのページの URL（HTTPS の GitHub Pages 等）を開きます。
   - 初回に「MIDI デバイスの制御を許可しますか？」と出たら **許可** をタップします。
   - 右上が `🎹 MIDI接続中` に変わればそのまま遊べます。
3. **補足**
   - Chrome のメニューから「ホーム画面に追加」をしておくと、アプリのようにフルスクリーンで起動できます。
   - 機種によっては Android の Web Audio 発音が Mac / iPad よりわずかに遅延することがあります。

## 📱 iPad で MIDIキーボードを繋いで遊ぶ

### なぜ Safari だと MIDI キーボードが反応しない？

iPad 標準の Safari（および iOS 版 Chrome/Firefox）は WebKit の制約により **Web MIDI API に未対応** です。
そのため、以下の2通りの使い方を用意しています。

### 方法A：MIDIキーボードを直接繋ぐ（おすすめ）

1. **ハードウェア接続**
   - **USB-C 端子の iPad**: USB-C ⇔ USB-B / USB-C ケーブル（または USB-C ハブ）で MIDI キーボードを接続します。
     - バスパワー消費が大きいキーボードの場合は、給電対応の USB-C ハブを使うと安定します。
   - **Lightning 端子の iPad**: Apple 純正 **Lightning - USBカメラアダプタ** 経由で接続します。
   - **Bluetooth MIDI 対応キーボード**: Bluetooth MIDI 設定アプリ（GarageBand や MIDI 機器メーカーのアプリ、または Web MIDI Browser 内の BLE MIDI 接続画面）からペアリングします。
2. **Web MIDI 対応ブラウザで開く**
   - App Store から **Web MIDI Browser**（定番の Web MIDI API 対応ブラウザ）をインストールします。
   - Web MIDI Browser でこのページの URL（GitHub Pages 等）を開くと、接続した MIDI キーボードを自動で認識します。
3. **音が出ないときの確認**
   - iPad 本体の **消音モード（コントロールセンターのベルアイコン）** がオフになっているか確認してください。
   - 画面を一度タップすると iPadOS の音声再生ロックが解除されます。

### 方法B：ケーブルなしで遊ぶ（標準 Safari）

- 標準 Safari で開いた場合は自動で **タッチ鍵盤モード** になります。
- 画面下部の大きなピアノ鍵盤は **マルチタッチ和音対応** なので、そのまま iPad 単体でも遊べます。
- Safari の「共有」→「ホーム画面に追加」をしておくと、アプリのようにフルスクリーンで起動できます。

## 📺 最大化モード＆うっかりスワイプ終了の完全防止

- **アプリ内の `⛶` 最大化モード**:
  - 右上の `⛶` ボタン（または `⚙️` 設定内）でトップバーを隠し、ステージと鍵盤を画面いっぱいに最大化します。
  - PC / Android Chrome ではブラウザ枠ごと全画面化（Fullscreen API）し、画面スリープ防止・引き下げリロード防止・タブ誤閉じ警告も自動で有効になります。
  - 子どもが誤タップしても戻らないよう、画面上部中央の **`🔒 1びょう長押しで解除`**（または PC の `Esc`）で解除します。
- **iPad で下端からのホームスワイプ終了まで完全に防ぐ方法（OS 公式機能）**:
  - iPadOS の仕様上、画面下端からのホームスワイプは Web アプリ単体では無効化できません。
  - **設定 → アクセシビリティ → アクセスガイド** を ON にしておき、この画面を開いて **電源ボタンを 3 回押し** すると、ホームスワイプ・通知スワイプ・アプリ切り替えを完全にロックできます（解除も電源ボタン 3 回押し＋パスコード）。

## 🎹 ミニキーボード（25鍵・32鍵）でのコツ

- どのゲームも **「やさしい」／「まつモード」ではオクターブ違いの同じ音名（低いド・高いドなど）も正解** として判定します。
- 画面下部の鍵盤は `🎹 1オクターブ` / `🎹 2オクターブ` ボタンで表示幅を切り替えられます。
